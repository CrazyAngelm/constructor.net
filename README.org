#+title: constructor.net (MVP)

Минимальная документация для разработки и поддержки.

* О проекте
- Монорепозиторий: =frontend/= (Next.js + API routes) и =common/= (общий TS-пакет).
- Проект находится на стадии MVP.
- Бэкенд реализован через Next.js API routes в =frontend/pages/api=.

* Стек
- Next.js 12, React 18, TypeScript
- Prisma ORM + MySQL
- NextAuth (пароль + Yandex OAuth)
- YooKassa
- Nodemailer

* Структура репозитория
- =frontend/pages= — страницы и API routes
- =frontend/components= — UI-компоненты
- =frontend/lib= — запросы, DTO, mailer, платежи
- =frontend/prisma/schema.prisma= — схема БД
- =common/= — общий пакет (минимально используется)
- =docker-compose*.yml=, =Makefile= — инфраструктура локальной разработки

* Локальная разработка (Docker)
Из корня репозитория:
#+begin_src bash
make build
make up
#+end_src

Сервисы:
- frontend на =127.0.0.1:80=
- db — MySQL 8 (учетки в =docker-compose.development.yml=)
- adminer на =http://localhost:8080= (если включить профиль =tools=)

* Переменные окружения
Основные переменные:
- =DATABASE_URL=
- =NEXTAUTH_URL=
- =NEXTAUTH_SECRET=
- =MAILER_USER=, =MAILER_PASS=
- =YOOCHECKOUT_SHOP_ID=, =YOOCHECKOUT_KEY=
- =UPLOAD_IMAGE_TASK=, =DOWNLOAD_IMAGE_TASK=
- =SC_SERVER_SIDE_API_URL= (опционально)

Файл с примером: =env.org=.

* Текущее развертывание
- На сервере проект запускается не через Docker.
- Используется =pm2=, запуск напрямую из =frontend/=.
