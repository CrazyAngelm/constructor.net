#+title: Пример файла frontend/.env

**  Переменные

  | Название              | Описание                                          |
  |-----------------------+---------------------------------------------------|
  | =DATABASE_URL=        | url базы данных                                   |
  | =NEXTAUTH_URL=        | имя домейна на котором происходит авторизация     |
  | =NEXTAUTH_SECRET=     | Секретный код авторизации, для шифрования jwt     |
  | =UPLOAD_IMAGE_TASK=   | Расположение загрузки изображений на сервер       |
  | =DOWNLOAD_IMAGE_TASK= | Расположение из котрого скачиваются изображения   |

** Пример 
  #+begin_src
      DATABASE_URL=mysql://ng_user:ng_user_passwort@db/ng 

      NEXTAUTH_URL=http://localhost
      NEXTAUTH_SECRET=07c7c5asdaec6a8fs588234jklsa265a

      YANDEX_ID=07c7c53baec648f7a76588fbea8d265a
      YANDEX_SECRET=d07ed54a3f3b41efadd05ca7baa6f4c6

      UPLOAD_IMAGE_TASK=public/uploads/task
      DOWNLOAD_IMAGE_TASK=/uploads/task
  #+end_src
