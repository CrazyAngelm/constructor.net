# Публикация курсов

В веб-версии управление находится в личном кабинете: **Панель администрирования → Публикация курсов**. Кнопки также есть в разделе **Курсы**, в редакторе выбранного курса.

- Новый курс сохраняется как черновик. Можно добавлять папки и задания, не открывая курс пользователям.
- Администратор видит черновик в конструкторе с явной отметкой. Обычный пользователь его не видит.
- **Сохранить** сохраняет изменения. **Опубликовать курс** открывает сохранённые материалы пользователям, имеющим доступ по подписке.
- **Снять курс с публикации** скрывает курс из каталога. Уже сохранённые конспекты пользователей остаются.
- Изменения уже опубликованного курса доступны после сохранения. Если весь курс ещё в разработке, сначала снимите его с публикации. Отдельного согласования каждого задания или сохранения предыдущей опубликованной редакции здесь нет.
- На основном сайте **Обновить каталог** читает рабочую базу. Это не кнопка публикации: новый курс остаётся черновиком до нажатия **Опубликовать курс**.
- Тестовая версия на порту 8443 использует отдельную базу и получает каталог с основного сайта. Тестовые пароли не подходят для основного сайта.

С 1 октября 2026 года веб-версия работает на основном адресе. В личном кабинете сохранена ссылка **Скачать приложение для Windows** на существующий установщик. Замена сайта не переустанавливает Windows-приложение.

Готовый конспект публикуется отдельно: сохраните его в опубликованном курсе и нажмите **Опубликовать конспект**. Пользователь открывает программу через **Программы LabStudio → Открыть свою копию**. Редактирование копии не затрагивает авторский оригинал.
