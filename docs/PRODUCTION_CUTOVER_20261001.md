# Основной сайт: переключение 1 октября 2026

Адрес: https://labstudio-inc.ru. Версия приложения: `20261001-programs`, Next.js build ID `VD8rnSPFh3DiPngkkoPem`.

## Данные и приложение

- Сохранена исходная рабочая база `labstudio` на прежнем MariaDB. Миграции добавляют поля и таблицы; исходные аккаунты, пароли, роли, подписки, платежи и старые конспекты не заменяются тестовой базой.
- Проверены исходные 155 аккаунтов, 164 подписки, 2 229 платежей, 36 старых конспектов. 25 ранее опубликованных программ доступны через библиотеку веб-конструктора. Остальные записи также сохранены в базе.
- 10 конспектов и 2 личные папки из тестовой версии перенесены в подтверждённый основной административный аккаунт LabStudio. Тестовые аккаунты, пароли и административные права не переносились.
- Старые тарифы сохранены для действующих подписок; для новых покупок предлагаются 299 / 399 / 499 / 599 / 999 ₽. Списки курсов безлимитных лицензий материализованы для совместимости с прежним приложением и откатом.
- Основной сервис: `labstudio-web.service`, порт `127.0.0.1:18082`, код `/srv/labstudio-web/current`, секреты `/srv/labstudio-web/production.env`.
- Старый код `/var/www/constructor.net` не перезаписан. Nginx продолжает отдавать прежние `/uploads/`, `/boundles/` и `/docs/`; ссылка на Windows-установщик сохранена. Боты поддержки не отключаются.

## Проверка перед переключением

На отдельной копии базы проверены: вход новой и старой версии, старые и новые безлимитные подписки, Basic-auth приложения без браузерных cookies, конвертация и повторное сохранение 25 программ / 408 элементов, доступность 149 используемых изображений. Проверены SMTP-аутентификация и чтение подтверждённого платежа с повторным callback без списания.

Отдельный browser/API тест на изолированной базе проверяет публикацию администратором, фильтрацию по курсу подписки, независимую копию, запрет изменения оригинала и сохранность личного изображения после снятия публикации.

После смены nginx обязательна проверка публичного входа, подписки, копирования программы, сохранения и чтения загруженного изображения, тарифов, ссылки на приложение и браузерных ошибок. Только после успеха останавливается прежний PM2-процесс `labstudio-frontend`.

## Резервная копия и откат

Серверная копия: `/srv/labstudio-preview/backups/production-20261001/`. Содержит старый сайт целиком (`original-app`), исходную конфигурацию nginx, исходный дамп и свежий дамп непосредственно перед миграциями (`before-cutover.sql`). Дампы также скопированы в закрытую локальную папку проекта `private/preview`; контрольные суммы сверяются при передаче. В Git секретов и дампов нет.

Чтобы вернуть старый интерфейс, root запускает:

```bash
bash /srv/labstudio-web/rollback-production.sh
```

Скрипт проверяет сохранённую старую сборку, запускает прежний PM2-процесс, ждёт готовности, сохраняет текущую конфигурацию nginx и возвращает основной upstream на порт 3000. **Старый SQL-дамп при обычном откате не восстанавливать**: общая рабочая база должна сохранить новые аккаунты и платежи. Веб-конспекты остаются в новых таблицах, даже если старый интерфейс их не показывает.

Секретные настройки, дампы и документы с данными клиентов предназначены только для закрытого хранения. Порт 8443 остаётся отдельной тестовой версией.
